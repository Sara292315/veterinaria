Aseguramiento de calidad

Calidad y pruebas del software

Cómo se construyó y se verifica VetConnect, aplicando los temas de Codificación y Pruebas del Software.

  • Codificación Validación defensiva de entradas, funciones puras y módulos separados (validators, database, app), con control de versiones en Git.
  • Pruebas (xUnit) Batería con pytest: unitarias de caja negra (valores límite) y de caja blanca (cada rama), de integración (API + SQLite) y dobles de prueba (mock) para simular fallos de base de datos.
  • Cobertura El pipeline exige un mínimo del 90 % de cobertura de código.
  • Integración continua GitHub Actions ejecuta las pruebas en cada push y publica el reporte de cobertura.
  • Mantenimiento Registro de fallos corregidos y plan de mantenimiento en docs/registro_fallos.md.

Términos y condiciones de uso

Condiciones generales para el uso de esta plataforma académica.

  1. VetConnect es un prototipo académico desarrollado con fines educativos; la información mostrada es de carácter ilustrativo.
  2. Los datos ingresados en los formularios (propietario, mascota y cita) se utilizan únicamente para organizar la solicitud dentro de la plataforma.
  3. La veterinaria es responsable de confirmar la disponibilidad real de horarios; la solicitud enviada no garantiza la cita hasta recibir confirmación.
  4. El usuario se compromete a proporcionar información veraz sobre sí mismo y sobre su mascota.
  5. La plataforma podrá evolucionar hacia una versión funcional completa, momento en el cual estos términos podrán actualizarse.
